Kex is a functional language with Ruby-like syntax, immutability by default,
and an Elixir-style process model.

- **[Guide](/guide/0.4.0-alpha/)** — the language, from the first value to processes.
- **[Standard Library](/prelude/)** — every module, type and trait that ships with Kex, generated from its source.
- **[Tey](/tey/)** — the package manager and build tool.

Machine-readable entry points: [llms.txt](/llms.txt) and [llms-full.txt](/llms-full.txt).
