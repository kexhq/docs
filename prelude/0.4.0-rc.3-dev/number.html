type Integer #

Implements Monoid, Group, Blankable, Truthyable.

Whole numbers, of arbitrary size.

Integer has no width limit: factorials and cryptographic moduli are ordinary values, not a special big-number type you have to opt into.

Integer and Float are one numeric tower: they compare and order across the boundary, so 0 == 0.0 is true and [1, 2.5, 3].sort works. What differs is the arithmetic. / on two integers is integer division, and sqrt answers a Float because a square root generally is one.

7 / 2          # => 3      (integer division)
7.0 / 2.0      # => 3.5
16.sqrt        # => 4.0    (a Float, even from an Integer)
(-7).modulo(3) # => 2      (mathematical modulo, not C remainder)

type Float #

Implements Blankable, Truthyable.

Double-precision floating-point numbers.

A Kex Float is always finite. An operation that would produce NaN or Infinity raises instead: the same rule the BEAM enforces, where those two values cannot exist at all. So a Float you are holding is always a real number, and there is no nan? to check for.

Float and Integer compare and order across the boundary; see Integer for the rest of the numeric tower.

3.7.floor      # => 3
3.7.round      # => 4
(-3.7).toInteger  # => -3   (truncates toward zero)

format #

format(parts: [String], values: [Any]) -> NumberFormat

Builds a NumberFormat from a digit pattern, for to(String, format).

The pattern is checked during compilation (by validateFormat), so a mistake in it fails the build instead of leaving text out at run time.

  • 0 is a required digit: 000 pads the integer part to three digits, and .00 always writes two decimals.
  • # is an optional digit: #.## writes at most two decimals and drops trailing zeros. Optional digits come before required ones in the integer part (#0) and after them in the decimals (.0#).
  • . starts the decimals. The value is rounded to as many decimals as the pattern allows, with ties away from zero.

The integer part always has at least one digit, so #.00 writes 0.50, never .50. A value that rounds to zero has no minus sign.

Parameters
parts
the literal pieces of the tagged literal
values
the interpolated values

Returns the format

Examples
1.5.to(String, Number.format`#.00`)   # => Just("1.50")
1.5.to(String, Number.format`#.##`)   # => Just("1.5")
2.0.to(String, Number.format`#.##`)   # => Just("2")
7.to(String, Number.format`000`)      # => Just("007")
