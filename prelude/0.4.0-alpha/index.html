BitsThe `Bits` module provides bitwise operations on `Integer`. ConsoleANSI terminal styling. Color constants become empty strings when Kex is started with --no-colors, so callers can compose them without branching. DigestCryptographic content digests. Hex strings are used at the public boundary so Kex programs never need to handle backend-specific binary values. ENV`ENV` is an immutable `Map<String, String>` snapshot of the process environment, taken once at startup. It supports all regular `Map` operations — `get`, `has?`, `keys`, `count`, `each`, etc. EvaluatorSandboxed evaluation of Kex source code at runtime. FS FS.FileA capability: every member reaches the real filesystem, so a test can replace the whole thing for a lexical region with `with FS.File = ...` instead of mutating global mock state (kexhq/kex#143). The boundary is here rather than on `FS`, because `FS.Path` below is pure string work with no implementation to substitute. FS.PathLexical path algebra: pure string manipulation, no filesystem access, so every answer is the same whether or not the path exists. POSIX separators only for now. FS.Directory HttpA capability: every member performs a real network request, so a test can replace it for a lexical region with `with Http = ...` rather than mutating global mock state (kexhq/kex#143). IO JSON Kex Kex.Kernel Kex.Feature Kex.InterfaceReturns the pretty-printed representation of any value as a STRING — the same form the REPL echoes. Universal: reachable on every type through UFCS. MathThe `Math` module provides standard mathematical constants and functions. All trigonometric functions operate in radians. A Kex `Float` is always finite, so a domain error (`Math.sqrt(-1.0)`) or an overflow (`Math.exp(1000.0)`) raises rather than producing `NaN` or `Infinity` — the same rule BEAM enforces, where those two values cannot exist at all. Mock Mock.FS Mock.Http Mock.ENVOverlays the process environment, so a test can say what `ENV` holds instead of depending on how it was launched. `unset` is separate because a variable being ABSENT is an answer programs act on. Byte offsets are zero-based and relative to the cooked literal body. AssertFocused assertions are ordinary Kex stdlib functions layered on the primitive `assert`, so adding another helper does not require compiler or runtime work. Time Date DateTime Duration Period── Periods ─────────────────────────────────────────────────────────────── Type UnitsThe time units are prelude-global, because every unit module measures against the same dimensions — `Units.SI` defines `Watt * Hour` with the `Hour` declared above, and future domains do the same. That makes `Hour` correct but not obviously located, so the same constructors are reachable under `Units` too, for call sites that would rather name where a unit comes from. These are aliases, not copies: each binds the identical constructor, so `Units.Hour` and `Hour` match the same patterns and compare equal. WebA small, WEBrick-style web server API. Configuration is immutable: mounting a route returns an updated server, and `start` hands that configuration to the BEAM runtime.
